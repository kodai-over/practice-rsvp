# 用語リスト（整理前の棚卸し）

アプリ（LIFF）・LINE のメッセージ（Bot の返事・カード）・スプレッドシートの見出しで、いま使っている言葉の一覧です。
用語を統一するための下書きで、**⚠ は同じものを別の言葉で呼んでいる、または古くなった言い方**です。

「場所」の略号：アプリ＝LINE内アプリの画面、Bot＝Bot の返事（テキスト）、カード＝Flex メッセージ、シート＝スプレッドシート

## 古くなっている言い方（直す候補）

- **Bot の返事「アプリの「＋ 登録」から入力してください」**（読み取りエラーの2か所。apps/gas/src/app/webhook.ts）：今は「登録」というメニューがなく、「募集」の右上の＋から登録する
- **確認カード「グループへの募集は、登録したあとアプリの練習画面からもできます。」**（packages/shared/src/flex.ts）：今は「募集」で練習を開いて送る
- **「予定」の詳細「直す・消すときは「募集」のこの練習から」**：ほかの画面は「編集」「削除」

## 統一するときに決めること（案）

1. **練習／予約／予約情報／チケット**：登録前は「予約」、登録後は「練習」、のように分けるか、1つにそろえるか
2. **保留／未定**：△ を「未定」に寄せるか、「保留」に寄せるか（記号ボタン・タブ・詳細・グループへの文・シートの値）
3. **出欠／回答／RSVP**：ボタン・画面名は「RSVP」のままにし、ほかは「出欠」か「回答」に寄せるか
4. **予約者／登録した人／予約した人**、**一般／一般メンバー／メンバー**
5. **募集先／送り先**、**入っている／所属**
6. **削除／消す／取り消す**、**編集／直す**
7. **スタジオ代／料金／金額**、**1人 ¥／PER PERSON**、**GOING** などの英語の見出しを残すか
8. **募集済／募集済み**、**終了／終わった**、**登録のみ／登録だけ**

シートの見出し（「状態」「回答」の値など）を変えるときは、今あるデータの読み替えが要るので、画面の文言とは分けて考えます。
