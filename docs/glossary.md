# 用語集

アプリ（LINE内アプリ・参加リンクのページ）、Bot の返事、LINE のカード、案内文（docs/）で使う言葉の決まりです。
**ユーザーに見える文字列は、この用語集に従って書きます。** 新しい言葉が要るときは、先にここへ足してから使います。

- 「使わない言い方」は、同じ意味で書かないようにする言葉です。
- コード（変数名・型・コメント）は対象外です。コードでは「チケット」「練習（practice）」も使ってよいです。
- スプレッドシートのシート名・見出し・値は変えません（下の「シートの値と画面の表示」を参照）。

## 表記のきまり

- 英語の見出しは使わず、日本語にする。ただし、チケットの曜日（SUN, MON…）と画面名の「RSVP」はデザインのため英語のまま（ボタン名は「回答」）。
- 空のときの表示などの1文は「。」で終える（例：「登録されている予約情報はありません。」）。
- Bot の合言葉は「予約情報」。以前からの「練習」でも一覧を返す。「予約」の一語は会話で出やすいので反応しない。
- 次は例外として残す：アプリ名「スタジオ練出欠管理」、カレンダーに入る予定の題名「ダンス練習」。

## シートの値と画面の表示

シートの見出しと値は変えず、画面に出すときだけ言い換えます。

| シート | 画面 |
| --- | --- |
| 回答の値「保留」 | 未定 |
| シート名「練習」「出欠」 | 予約情報、回答 |
| 見出し「送り先グループ」「ふだんの送り先グループ」「所属グループ」 | 送り先、ふだんの送り先、所属 |
| 見出し「料金」「1人料金(調整)」 | スタジオ代、1人あたり |
| 設定の種別「標準料金」 | スタジオ代の料金表 |

## 新しい用語を足すとき

1. 上の表に同じ意味の言葉がないか確かめる（あればそれを使う）。
2. なければ、当てはまる表に「用語・意味・使わない言い方」を1行足す。
3. 足した言葉を画面・Bot・案内文で使う。
