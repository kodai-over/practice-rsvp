# グループでの動作確認チェックリスト

個別トークでの確認が済んだあと、テストグループにBotを招待して確かめる項目です。

## テスト前の注意

- [ ] **本番グループに募集が流れないか**：Botが本番グループにも入っていて登録済みのグループが2つ以上ある場合、募集先は各メンバーの「既定のグループ」で決まる（グループが1つだけなら自動でそこが募集先になる）。確認カードの「募集先」がテストグループだけになっているか、毎回見る
- [ ] 募集はプッシュ送信なので、月200通の枠を消費する（応答は消費しない）
- [ ] LINE Developers の設定で「グループトーク・複数人トークへの参加を許可する」が有効になっている

## 1. 招待と退出

| 確認 | 操作 | 期待される結果 |
| --- | --- | --- |
| [ ] | Botをグループに招待する | グループには何も送られない。設定シートにグループIDとグループ名が追加される |
| [ ] | 招待後にLINEでグループ名を変える | 1時間以内（毎時の処理のあと）に、アプリの管理画面と、そのあと作る確認カードの「募集先」が新しい名前になる（送信済みのカードは古い名前のまま） |
| [ ] | 複数人トーク（room）に招待する | 名前が「グループN」になる（名前を取得できないため自動ではそろわない）。最近のLINEアプリでは複数人トークはグループに統合されていて、作ると「グループ」として扱われる |
| [ ] | 他の公式アカウントがいるグループに招待する | Botは入れずに抜ける（LINEの仕様で、1つのトークに公式アカウントは1つしか入れない）。設定シートには載らない。招待時の名前の取得が失敗したり、退出の知らせが届かなかったりして「グループN」が残った場合も、毎時の処理で3回続けて見つからなければ消える（最短2時間ほど。遅れることもある）。複数人トーク（IDが R で始まる）は自動では消えないので手で消す |
| [ ] | Botを退出させ、再度招待する | 退出で設定から消え、再招待で戻る。退出中は、そのグループに流した練習のグループ名が「（退出したグループ）」と表示される |

## 2. 募集の送信

| 確認 | 操作 | 期待される結果 |
| --- | --- | --- |
| [ ] | 個別トークの確認カードで「登録して募集」を押す（アプリが開くので、募集先を選んで「登録して募集」） | テストグループに募集カードが届く。日時・場所・予約者・上限・メモが正しく表示される（広さ・料金は載らない）。ボタンは ○ △ ✕ と「アプリを開く」 |
| [ ] | 予約を複数件まとめて登録して募集する | 1通のカルーセルにまとまる（12件ごとに区切られる） |
| [ ] | アプリで2件登録し、1件目の募集先をグループ1、2件目をグループ2にする | グループ1には1件目だけ、グループ2には2件目だけが届く |
| [ ] | 既存の練習に続く予約（「延長」の印）を「分ける」で分け、続きの部分に別のグループを選んで登録する | 延長の部分は既存の練習に足され、続きの部分は別の練習としてそのグループに届く |
| [ ] | まとめた予約の日時を直す | 「分ける」が消える（直した内容が分けたときに消えないように） |
| [ ] | 19:00〜21:00 と 21:00〜22:00 を続けて登録し、募集先を別々にする（スクショなら「分ける」を押してから） | 別々の練習になり、それぞれのグループに届く。募集先が同じなら19:00〜22:00 の1件にまとまる |
| [ ] | アプリの「募集」で練習を開き、グループに送る | 送れる。同じグループへの2回目は送れない（二重送信の防止） |
| [ ] | 確認カードの「登録のみ」で登録する | グループには何も届かない |
| [ ] | 練習を削除する | グループには通知されない（仕様どおり） |

## 3. 出欠ボタン

| 確認 | 操作 | 期待される結果 |
| --- | --- | --- |
| [ ] | ○（行く）△（保留）✕（行かない）を押す | 本人の発言として「10/30 行きます」のような文がグループに出る。Botは返信しない。出欠シートに記録される |
| [ ] | 回答を変える（行く→行かない など） | 上書きされ、記録は1行のまま |
| [ ] | **Botを友だち追加していない人**が押す | 記録される。名前はグループでの表示名になる |
| [ ] | 上限人数に達した後に別の人が「行く」を押す | グループに「…の練習は満員です」と返信が出て、みんなに見える。状態が「満員」になる |
| [ ] | 満員の練習で1人が「行かない」に変える | 状態が「募集中」に戻る |
| [ ] | 過去の日付の練習のボタンを押す | 「この練習は終了しました」と返る |
| [ ] | 削除済みの練習のボタンを押す | 「練習が見つかりません」と返る |
| [ ] | 複数人がほぼ同時に押す | 全員分が記録される |

## 4. グループでの発言

| 確認 | 操作 | 期待される結果 |
| --- | --- | --- |
| [ ] | 「練習」と送る | **そのグループに募集した練習だけ**が一覧に出る。募集していない練習は出ない |
| [ ] | 普通の会話、または「練習」の前後に文字を付けて送る | 反応しない（「練習」は前後の空白を除いて完全一致のときだけ反応する） |
| [ ] | スクショや予約メールの文章を送る | 反応しない（登録できるのは個別トークだけ） |

## 5. グループからアプリを開く

- [ ] 募集カードの「詳細」、一覧の「アプリで見る」から LINE内アプリが開き、該当の練習が表示される
- [ ] Botを友だち追加していない人でもアプリにログインでき、アプリで出欠を出せる
- [ ] ボタンで出した出欠とアプリの表示が一致する

## 6. 時間が経ってから起きること

- [ ] キャンセル期限前の警告は、**グループではなく予約者の個別トーク**に届く。最低人数に届いていない練習だけが対象
- [ ] 日付を過ぎた練習は毎時の処理で「終了」になり、ボタンでもアプリでも回答できなくなる

## 7. 練習が見える範囲

グループを2つ用意し、片方にだけ入っている人を用意して確かめます。

| 確認 | 操作 | 期待される結果 |
| --- | --- | --- |
| [ ] | グループで発言する、または出欠ボタンを押す | 管理画面でその人に「（グループ名）に入っている」のチェックが付く。メンバーシートの「所属グループ」にグループIDが入る |
| [ ] | 新しい人をグループに招待する | 招待された人にチェックが付く |
| [ ] | グループの人を退会させる | その人のチェックが外れる |
| [ ] | 一度も発言していない人が、募集カードの「アプリを開く」を押す | 練習が表示され、その人にチェックが付く |
| [ ] | グループ1にだけ募集し、グループ2にしかいない人がアプリを開く | その練習は一覧に出ない。個別トークで「練習」と送っても出ない |
| [ ] | 同じ練習を、アプリの「募集」からグループ2にも流す | グループ2の人にも見えるようになる |
| [ ] | 管理者がアプリを開く | すべての練習が見える |

優先度が高いのは、テスト前の注意（本番グループへの誤送信）、3の「友だち追加していない人」と「満員」、4の「練習」の一覧、7の見える範囲です。
