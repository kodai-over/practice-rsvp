# 予約者向けの使い方（案内文）

LINEでそのまま送れる文面です。`<Botの友だち追加リンク>` は LINE Official Account Manager の「友だち追加」から取得して差し替えてください。

---

スタジオを予約したら、予約画面のスクショをBotに送るだけで予約情報を登録できるようになりました🙌
登録した予約情報はアプリの一覧に載り、メンバーはそこから回答できます。グループへの募集は、必要なときだけ流せます。

アプリで予約情報が見えるのは、予約者・送り先グループに所属している人・回答した人・管理者だけです。たとえば先にグループ1にだけ募集すると、グループ2にしかいない人には見えません。あとからグループ2にも流すと見えるようになります。

**最初に1回だけ**
Botを友だち追加してください → <Botの友だち追加リンク>
（スクショを送るためと、キャンセル期限前のお知らせを受け取るためです）

**登録のしかた**
1. スタジオを予約したら、予約完了画面か予約一覧のスクショをBotとの個別トークに送る（一度に3枚まで。4枚以上まとめて送ると読み取らずに断られます。1枚に複数の予約が写っていても大丈夫）
   - スクショの代わりに、予約完了メールなどの予約内容の文章をそのまま送っても登録できます
2. Botが読み取った内容のカードを返すので、日時・場所を確認
3. 次のどれかを押す
   - 「登録して募集」: アプリが開くので、内容を確かめ、予約情報ごとに送り先を選んで「登録して募集」を押します（ふだんの送り先が入っています）
   - 「登録のみ」: 登録のみします（グループには何も届きません）
   - 「やめる」: 登録しません（個人練習など）
4. アプリの一覧に載ります（登録した人は自動で「行く」になります）

**グループに募集したいとき**
- アプリの登録画面では、予約情報ごとの「送り先」で送るグループを選べます（1件目はグループ1だけ、2件目はグループ2だけ、など）。2件以上あるときは、下の「すべての予約情報の送り先」でまとめて付け外しもできます
- 登録したあとでも、アプリの「募集」で予約情報を開いて、グループを選んで送れます（同じグループに二重には送りません）。「募集」に並ぶのは自分が登録した予約情報です（管理者にはすべての予約情報が並びます）。「予定」に出るのは、所属グループに募集された予約情報と自分が登録・回答した予約情報だけです。管理者でも、所属グループの予約情報が「予定」に出ないときは、そのグループの募集メッセージの「回答」から一度開いてください
- アプリで開始時刻を変えると、終了が開始の1時間後より前にならないよう自動でそろえます（19:00〜21:00 の開始を 21:00 にすると 22:00 終了）

**そのほか**
- 登録した予約情報の時間・部屋・スタジオ代・人数・メモは、アプリの「募集」で予約情報を開いて「編集」から変えられます。「予定」から開いた画面では編集できません
- 内容が違うときは「登録して募集」でアプリを開いて編集してください（編集したあと、送り先を選ばなければ登録のみになります）。読み取れなかった項目があるときは「修正して登録」が出ます
- まとめた予約情報の日時・場所・スタジオ代を編集すると、「分ける」は使えなくなります。分けるときは先に「分ける」を押してください
- 予約情報を削除するときは、アプリの「募集」でその予約情報を左にスワイプして「削除」を押します（予約情報を開いて「編集」の「削除する」でも削除できます）。削除の前に確認が出ます。グループへの連絡は自動では送られないので、必要ならグループで伝えてください
- 予約情報の編集・中止・削除ができるのは、予約者と管理者だけです
- 同じ部屋で続けて延長予約したときは、前の予約情報の延長として更新されます（募集は出し直しません）
- 予約一覧に写っている過去の予約は自動で除きます。同じ部屋で続けて取った予約（19:00〜20:30 と 20:30〜21:00 など）は1つの予約情報にまとめます。別々の予約情報にしたいときは、アプリの登録画面でその予約情報の「分ける」を押し、それぞれに違う送り先を選んでください（送り先が同じならまとめます）
- 「横浜 301」のようにスタジオ名が写っていない画面は、最初の1回だけアプリでスタジオ名（例: worcle横浜）を入力してください。次からは自動で当てはめます
- スクショがないときは、アプリの「募集」の右上の「＋」から入力できます

**お願い**
スクショに電話番号やメールアドレスが写っていたら、その部分を切り取ってから送ってください（読み取りにGoogleのAIを使っています）。

**キャンセル期限の前に**
キャンセル料がかかる前に参加人数が少ないと、Botから個別にお知らせが届きます。お知らせのリンクから予約情報を開いて「編集」の「削除する」を押すか、アプリの「募集」で左にスワイプして削除し、必要ならグループで伝えてください。
