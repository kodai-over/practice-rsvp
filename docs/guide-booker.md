# 練習を登録する人向けの使い方（案内文）

LINEでそのまま送れる文面です。`<Botの友だち追加リンク>` は LINE Official Account Manager の「友だち追加」から取得して差し替えてください。

---

スタジオを予約したら、予約画面のスクショをBotに送るだけで募集できるようになりました🙌

**最初に1回だけ**
Botを友だち追加してください → <Botの友だち追加リンク>
（スクショを送るためと、キャンセル期限前のお知らせを受け取るためです）

**募集のしかた**
1. スタジオを予約したら、予約完了画面か予約一覧のスクショをBotとの個別トークに送る（何枚でもOK。1枚に複数の予約が写っていても大丈夫）
   - スクショの代わりに、予約完了メールなどの予約内容の文章をそのまま送っても登録できます
2. Botが読み取った内容のカードを返すので、日時・場所・送り先グループを確認
3. 合っていれば「この内容で募集」を押す → 選んだグループに募集が流れます

- 内容が違う／送り先を変えたいときは「修正して募集」から直せます
- 募集しない予約（個人練習など）は「やめる」を押すだけ
- 同じ部屋で続けて延長予約したときは、前の練習の延長として更新されます（募集は出し直しません）
- 予約一覧に写っている過去の予約は自動で除きます。同じ部屋で続けて取った予約（19:00〜20:30 と 20:30〜21:00 など）は1つの練習にまとめます
- 「横浜 301」のようにスタジオ名が写っていない画面は、最初の1回だけ「修正して募集」でスタジオ名（例: worcle横浜）を直してください。次からは自動で当てはめます
- スクショがないときは、アプリの「練習を登録」から入力できます

**お願い**
スクショに電話番号やメールアドレスが写っていたら、その部分を切り取ってから送ってください（読み取りにGoogleのAIを使っています）。

**キャンセル期限の前に**
キャンセル料がかかる前に参加人数が少ないと、Botから個別にお知らせが届きます。中止するときは、アプリでその練習を開いて「中止にする」を押すと、グループにも知らせます。
