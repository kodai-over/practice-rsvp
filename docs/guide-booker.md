# 練習を登録する人向けの使い方（案内文）

LINEでそのまま送れる文面です。`<Botの友だち追加リンク>` は LINE Official Account Manager の「友だち追加」から取得して差し替えてください。

---

スタジオを予約したら、予約画面のスクショをBotに送るだけで練習を登録できるようになりました🙌
登録した練習はアプリの一覧に載り、メンバーはそこから出欠を出せます。グループへの募集は、必要なときだけ流せます。

アプリで練習が見えるのは、予約した人・募集を流したグループに入っている人・出欠を答えた人・管理者だけです。たとえば先にグループ1にだけ募集すると、グループ2にしかいない人には見えません。あとからグループ2にも流すと見えるようになります。

**最初に1回だけ**
Botを友だち追加してください → <Botの友だち追加リンク>
（スクショを送るためと、キャンセル期限前のお知らせを受け取るためです）

**登録のしかた**
1. スタジオを予約したら、予約完了画面か予約一覧のスクショをBotとの個別トークに送る（何枚でもOK。1枚に複数の予約が写っていても大丈夫）
   - スクショの代わりに、予約完了メールなどの予約内容の文章をそのまま送っても登録できます
2. Botが読み取った内容のカードを返すので、日時・場所を確認
3. 次のどれかを押す
   - 「登録して募集」: アプリが開くので、内容を確かめ、予約ごとに募集先を選んで「登録して募集」を押します（ふだんの送り先が入っています）
   - 「登録のみ」: 登録だけします（グループには何も届きません）
   - 「やめる」: 登録しません（個人練習など）
4. アプリの一覧に載ります（登録した人は自動で「行く」になります）

**グループに募集したいとき**
- アプリの登録画面では、予約ごとの「募集先」で送るグループを選べます（1件目はグループ1だけ、2件目はグループ2だけ、など）。2件以上あるときは、下の「すべての予約の募集先」でまとめて付け外しもできます
- 登録したあとでも、アプリの「募集」で練習を開いて、グループを選んで送れます（同じグループに二重には送りません）
- アプリで開始時刻を変えると、終了が開始の1時間後より前にならないよう自動でそろえます（19:00〜21:00 の開始を 21:00 にすると 22:00 終了）

**そのほか**
- 内容が違うときは「登録して募集」でアプリを開いて直してください（直したあと、募集先を選ばなければ登録だけになります）。読み取れなかった項目があるときは「修正して登録」が出ます
- まとめた予約の日時・場所・料金を直すと、「分ける」は使えなくなります。分けるときは先に「分ける」を押してください
- 練習をやめるときは、アプリで練習を開いて「削除する」を押します（一覧から消えます）。グループへの連絡は自動では送られないので、必要ならグループで伝えてください
- 練習の修正・中止・削除ができるのは、登録した本人と管理者だけです
- 同じ部屋で続けて延長予約したときは、前の練習の延長として更新されます（募集は出し直しません）
- 予約一覧に写っている過去の予約は自動で除きます。同じ部屋で続けて取った予約（19:00〜20:30 と 20:30〜21:00 など）は1つの練習にまとめます。別々の練習にしたいときは、アプリの登録画面でその予約の「分ける」を押し、それぞれに違う募集先を選んでください（募集先が同じならまとめます）
- 「横浜 301」のようにスタジオ名が写っていない画面は、最初の1回だけアプリでスタジオ名（例: worcle横浜）を直してください。次からは自動で当てはめます
- スクショがないときは、アプリの画面下の「登録」から入力できます

**お願い**
スクショに電話番号やメールアドレスが写っていたら、その部分を切り取ってから送ってください（読み取りにGoogleのAIを使っています）。

**キャンセル期限の前に**
キャンセル料がかかる前に参加人数が少ないと、Botから個別にお知らせが届きます。やめるときは、アプリでその練習を開いて「削除する」を押し、必要ならグループで伝えてください。
