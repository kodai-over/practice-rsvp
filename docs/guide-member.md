# メンバー向けの使い方（案内文）

グループに送る文面です。友だち追加やログインは不要です。

---

練習の募集がBotから届くようになりました📣

**出欠**
募集メッセージの「行く／行かない」を押すだけ。押すと「10/21 行きます」と自分の発言として出ます。気が変わったら反対のボタンを押せばOK。

**今後の練習を見る**
- グループで「練習」とだけ送ると一覧が返ってきます
- 募集メッセージの「参加状況を見る」から、誰が来るか・1人いくらかを見られます
- アプリの「自分が行く」タブで、自分が行く練習だけ確認できます

**カレンダーに入れる**
募集メッセージの「カレンダーに追加」から、Googleカレンダー／iPhoneのカレンダーに入れられます。

**グループにいない人を誘うとき**
アプリで練習を開いて「ゲストを追加」に名前を入れるか、「参加リンク」をコピーして本人に送ってください。本人はブラウザで名前を入れて「行く」を押すだけです。

**名前が分かりにくいとき**
アプリの「設定」から一覧に出る名前を変えられます。

**メニュー**
Practice RSVP（Bot）を友だち追加すると、トーク画面の下に「練習を登録」「募集する」「予定を見る」「要望」のボタンが出ます。

**練習を登録する**
スタジオを予約したら、誰でも登録できます。予約画面のスクショか予約内容の文章をBotに送るか、アプリの「＋ 登録」から入力してください。

**改善要望**
メニューの「要望」か、アプリの「設定」→「要望を見る・送る」から、こうなったら便利・ここが使いにくい、などを送れます。送った要望は名前と一緒にメンバー全員に表示されます。
