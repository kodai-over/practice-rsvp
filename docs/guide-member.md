# メンバー向けの使い方（案内文）

グループに送る文面です。友だち追加やログインは不要です。

---

練習の募集がBotから届くようになりました📣

**出欠**
募集メッセージの「行く／保留／行かない」を押すだけ。押すと「10/21 行きます」と自分の発言として出ます。アプリでは ○（行く）△（保留）✕（行かない）で選べます。まだ決められないときは「保留」にしておき、決まったら押し直せばOK（保留は人数・割り勘には数えません）。アプリの「未定」タブで、返事がまだの練習を確認できます。

**今後の練習を見る**
- グループで「練習」とだけ送ると一覧が返ってきます
- 募集メッセージの「参加状況を見る」から、誰が来るか・1人いくらかを見られます
- アプリの「行く」タブで（行く練習は日付の部分が黒くなります）、自分が行く練習だけ確認できます

**カレンダーに入れる**
募集メッセージの「カレンダーに追加」から、Googleカレンダー／iPhoneのカレンダーに入れられます。

**グループにいない人を誘うとき**
アプリの「募集」で練習を開いて「ゲスト」に名前を入れるか、「参加リンク」をコピーして本人に送ってください。本人はブラウザで名前を入れて「行く」を押すだけです。

**名前が分かりにくいとき**
アプリの「自分」から一覧に出る名前を変えられます。

**メニュー**
Practice RSVP（Bot）を友だち追加すると、トーク画面の下に「登録」「募集」「予定」「要望」のアイコンのボタンが出ます。

**練習を登録する**
スタジオを予約したら、誰でも登録できます。予約画面のスクショか予約内容の文章をBotに送るか、アプリの画面下の「登録」から入力してください。

**改善要望**
メニューの「要望」か、アプリのどの画面でも画面下のナビにある「要望」から、こうなったら便利・ここが使いにくい、などを送れます。送った要望は名前と一緒に管理者だけに届きます。
