# メンバー向けの使い方（案内文）

グループに送る文面です。友だち追加やログインは不要です。

---

スタジオ練の募集がBotから届くようになりました📣

**回答する**
「参加者募集」のメッセージの「RSVP」を押すと、その募集の予約情報だけが並んだ画面が開きます。予約情報ごとに ○（行く）△（未定）✕（行かない）を選んでください。選んだだけではグループのトークには何も出ません。
回答したことをグループに知らせたいときは、同じ画面の「グループに伝える」を押すと、「○ 11/1(日) 行きます／△ 11/2(月) 未定です」のような1通が自分の発言として送られます。送る文はその場で書き換えられます（「遅れて行きます」と書き足す、など）。
知らせなくてよいときは「完了」を押せば「予定」に戻ります。回答は選んだ時点で記録されています。
まだ決められないときは「未定」にしておき、決まったら選び直せばOK（未定は人数・割り勘には数えません）。アプリの「未定」タブで、回答がまだの予約情報を確認できます。
※ 以前の募集メッセージの ○ △ ✕ も、これまでどおり使えます。

**今後の予約情報を見る**
- グループで「予約」とだけ送ると一覧が返ってきます
- 「RSVP」で開いた画面で予約情報を押すと、参加者（行く・未定・行かない）・1人あたりのスタジオ代・部屋の広さを見られます。一覧の金額はスタジオ代の合計です
- アプリの「行く」タブで（行く予約情報は日付の部分が黒くなります）、自分が行く予約情報だけ確認できます
- アプリに出るのは、所属グループに募集された予約情報と、自分が予約・回答した予約情報です。所属グループの予約情報が出ないときは、そのグループの募集メッセージの「RSVP」から一度開いてください

**カレンダーに入れる**
「RSVP」で開いた画面で予約情報を押し、「カレンダーに追加」から Googleカレンダー／iPhoneのカレンダーに入れられます。

**グループにいない人を誘うとき**
予約者に頼んでください。予約者はアプリの「募集」で予約情報を開き、「ゲスト」に名前を入れるか、「参加リンク」をコピーして本人に送れます。本人はブラウザで名前を入れて「行く」を押すだけです。

**名前が分かりにくいとき**
アプリの「自分」から一覧に出る表示名を変えられます。

**メニュー**
スタジオ練出欠管理（Bot）を友だち追加すると、トーク画面の下に「アプリを開く」ボタンが出ます。予定・募集・要望は、アプリの画面下のナビから選べます（登録は「募集」の右上の「＋」から）。

**予約情報を登録する**
スタジオを予約したら、誰でも登録できます。予約画面のスクショか予約内容の文章をBotに送るか、アプリの「募集」の右上の「＋」から入力してください。

**改善要望**
アプリのどの画面でも、画面下のナビにある「要望」から、こうなったら便利・ここが使いにくい、などを送れます。送った要望は名前と一緒に管理者だけに届きます。
